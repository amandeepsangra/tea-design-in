# Tea Design In 🍵

A modern, desktop-ready design editor built with React, Vite, and Electron. It allows users to create and edit "Tea Design Documents" (`.tea` files) using powerful canvas manipulation tools powered by Fabric.js.

## Features
- **Canvas Editor:** Advanced object manipulation, alignment, and layers.
- **Cross-Platform:** Works on Web, Windows, Mac, and Linux (via Electron).
- **GitHub Pages Ready:** Can be easily built and deployed as a static web app.

## Development

```bash
# Install dependencies
npm install

# Run locally in dev mode
npm run dev

# Build for web (and deploy to GitHub Pages)
npm run deploy

# Build for Electron
npm run build
```
